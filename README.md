# Fixed Risk Lot Calculator

A free, personal-use fixed-risk position sizing PWA. It runs as a static site, has no login, backend, database, or paid API, and can be hosted on GitHub Pages.

## Run locally

Use any static web server because ES modules and the service worker require HTTP:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080` and run the calculation tests with:

```bash
npm test
```

## Calculation model

- FX uses a 100,000-unit standard lot and 0.0001 pips, or 0.01 for JPY pairs.
- Cross-pair pip values are converted from quote currency to account currency through direct, inverse, or multi-hop rates.
- XAUUSD defaults to 100 oz/lot; XAGUSD defaults to 5,000 oz/lot.
- Lot size is floored to the instrument's volume step, keeping estimated risk at or below fixed risk.
- Commission, swap, spread, and slippage are intentionally excluded.

Rates try the browser-compatible Frankfurter public endpoint, then localStorage cache, then approximate built-in fallback rates. The calculator remains usable when offline. Broker contract specifications can vary; edit `src/instruments.js` if needed.

## Add an FX pair

Add the six-character symbol to `FX_SYMBOLS` in `src/instruments.js`. The base/quote currencies, JPY pip rule, contract size, and lot settings are generated by the shared specification factory.

## GitHub Pages

Push the repository to GitHub. The included workflow deploys the `main` branch to GitHub Pages. In the repository settings, set Pages' source to **GitHub Actions**. The generated HTTPS URL can be added to an iPhone, Android, Safari, Chrome, or desktop home screen.
